بناء ملف ESC1.apk تلقائياً عبر GitHub (مجاني)
================================================
لم أستطع إنتاج ملف APK مباشرة لأن بيئتي لا تملك أدوات أندرويد ولا اتصالاً بمستودعاتها. هذا المجلد مشروع أندرويد كامل جاهز، ويبني GitHub الملف نيابةً عنك.

الخطوات (من الحاسوب):
1) افتح github.com وسجّل الدخول، ثم أنشئ مستودعاً جديداً (New repository) باسم ESC1.
2) اضغط «uploading an existing file» وارفع كل محتويات هذا المجلد بالسحب، بما فيها المجلد المخفي .github
   (إن لم يُرفع .github: اختر Add file > Create new file واكتب الاسم  .github/workflows/build.yml  والصق محتوى الملف).
3) بعد الرفع افتح تبويب Actions وانتظر نحو 5 دقائق حتى يكتمل البناء (علامة ✓ خضراء).
4) افتح تبويب Releases، ستجد الإصدار «latest» وفيه الملف ESC1.apk. الرابط:
   https://github.com/<اسم-حسابك>/ESC1/releases/download/latest/ESC1.apk

التثبيت على الهاتف:
- نزّل ESC1.apk من الرابط على هاتف أندرويد 10 أو أحدث، وافتحه، واسمح بالتثبيت من هذا المصدر عند الطلب.
- يعمل التطبيق بدون إنترنت بالكامل. ملفات PDF والنسخ الاحتياطي تُحفظ في مجلد التنزيلات.
- التطبيق فارغ من البيانات، وبياناته على الهاتف فقط.
- إن ظهر خطأ في البناء داخل Actions، أرسل لي نص الخطأ.
